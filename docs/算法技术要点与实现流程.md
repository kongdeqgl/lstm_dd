本文说明当前项目中“有向图网络 + 链路级单向LSTM”算法的完整实现，覆盖：

- 仿真算料如何转换成图训练数据；
- 如何维护节点和有向链路历史；
- 如何构造过去10步、未来3步的监督样本；
- 节点特征、边特征和有效性掩码如何构造；
- 变节点数量图如何张量化；
- 图网络和LSTM如何联合工作；
- 训练、验证早停、测试和模型保存如何实现；
- 在线推理如何复用同一套预处理和历史逻辑；
- 每个阶段对应的源代码文件和关键函数。

当前实现面向单簇内的有向链路SINR预测。不同簇可以使用同一个模型参数，但每个簇分别维护自己的历史缓存。

## 2. 算法目标与当前默认参数

对查询有向链路 `source → destination`，使用过去 `T=10` 个时隙的簇内图序列，直接回归未来 `H=3` 个时隙的SINR：

```text
输入：G(t-9), G(t-8), ..., G(t)
输出：SINR(t+1), SINR(t+2), SINR(t+3)
```

当前正式配置位于：

```text
config/formal_graph_training.toml
```

主要参数：

| 参数 | 当前值 | 含义 |
| --- | ---: | --- |
| `sampling_interval_ms` | 1000 | 时隙间隔1秒 |
| `history_steps` | 10 | 使用过去10个图快照 |
| `forecast_steps` | 3 | 预测未来3步 |
| `hidden_dim` | 64 | 节点、边和图消息隐藏维度 |
| `link_dim` | 64 | 每时隙查询链路表示维度 |
| `lstm_hidden_dim` | 64 | LSTM隐藏维度 |
| `graph_layers` | 2 | 有向图消息传递层数 |
| `lstm_layers` | 1 | 单向LSTM层数 |
| `min_observation_ratio` | 0.8 | 10步中至少8步有新SINR观测 |
| `max_consecutive_missing_steps` | 2 | 最多连续缺失2步 |
| `max_node_age_ms` | 2000 | 节点状态最大允许年龄 |
| `max_link_age_ms` | 2000 | 链路SINR最大允许年龄 |

### 5.2 转换流程伪代码

```text
function convert_exports(run_root, output_dir):
    runs = discover all <run_id>/export/manifest.json
    descriptors = []

    for manifest in runs:
        validate manifest structure
        validate CSV part paths and SHA-256
        load scenario metadata
        descriptors.append(run descriptor)

    for descriptor in descriptors:
        episode = convert_run(descriptor)
        write episode to episodes/<scene_id>.json
        calculate episode SHA-256
        add shard entry to index

    write index.json
    optionally write smoke_index.json
```

## 7. 双时间历史缓存与因果性

### 7.1 两种时间

每条节点或链路记录同时保存：

```text
observation_time_ms：记录对应的观测时刻
arrived_at_ms：记录实际进入预测系统的时刻
```

缓存结构：

```text
nodes[node_id][observation_time_ms] = Received(record, arrived_at_ms)
relations[(source_id, destination_id)][observation_time_ms] = Received(record, arrived_at_ms)
```

只有同时满足以下条件的记录才对某个快照可见：

```text
observation_time_ms <= grid_time_ms
arrived_at_ms <= cutoff_ms
```

对应代码：

```text
src/sinr_predictor/data/history.py::_visible
```

### 7.2 批次原子写入

`HistoryCache.ingest()`先检查整批冲突，再统一写入。

```text
function ingest(request, arrival_time):
    node_batch = validate all node records
    relation_batch = validate all relation records

    if same identity + same observation time has different content:
        reject entire request

    write all node records
    write all relation records
```

完全相同的重复记录是幂等的；内容冲突时整批拒绝，避免缓存只写入一半。

### 7.3 节点连续会话

`active_since()`用于识别节点当前连续在线区间。以下情况会重新开始会话：

- 节点先发送 `member_present=0`，之后再次出现；
- 两次节点观测间隔超过 `continuity_gap_ms`。

旧会话中的链路SINR不能接到新会话之后继续使用。

### 7.4 训练和推理复用同一逻辑

离线训练在 `dataset.py` 中按 `received_time_ms`回放frame，写入同一个 `HistoryCache`。在线推理在 `Predictor`中同样写入 `HistoryCache`。

因此：

```text
训练历史构造规则 = 在线推理历史构造规则
```

## 8. 监督样本构造

对应代码：

```text
src/sinr_predictor/data/dataset.py::build_samples
```

### 8.1 真值缓存和输入缓存分离

实现中使用两个缓存：

```text
truth：包含完整episode，仅用于读取未来标签
history：只回放到当前reference，构造模型输入
```

这可以防止未来信息进入历史特征。

### 8.2 样本构造伪代码

```text
function build_samples(episode):
    truth = ingest all frames of episode
    history = empty cache

    first_reference = first_time + 9 * interval
    last_reference = last_time - 3 * interval

    for reference in valid reference times:
        ingest into history only frames received <= reference
        prune expired cache records

        queries = configured query relations
                  or relations already visible before reference

        snapshots = build 10 causal graph snapshots
        windows = build one query window per directed relation
        statuses = check prediction eligibility

        for each query:
            target[0] = truth SINR at reference + 1 second
            target[1] = truth SINR at reference + 2 seconds
            target[2] = truth SINR at reference + 3 seconds
            target_mask = whether each future target is truly valid

        emit ForecastSample
```

`stride_steps`控制相邻训练样本的间隔。当前正式配置为10，表示每10个可用基准时隙构造一个样本，用于降低训练时间和样本重叠度。

## 9. 图快照和查询窗口

对应代码：

```text
src/sinr_predictor/data/preprocess.py::build_snapshots
src/sinr_predictor/data/preprocess.py::build_query_window
```

### 9.1 历史时间网格

对于参考时刻 `reference`，构造：

```text
reference - 9秒
reference - 8秒
...
reference - 1秒
reference
```

### 9.2 节点进入快照的条件

节点必须满足：

- 当前时隙之前存在可见记录；
- `member_present = 1`；
- 经纬高和NED三维速度字段真实提供；
- 节点记录年龄不超过 `max_node_age_ms`。

### 9.3 空间边集合

当前不默认构造完整的 `N × (N-1)` 全连接图。候选边为：

```text
历史缓存中出现过的有向关系
∪
本次明确查询的有向关系
```

如果端点当前不可用，该边不进入快照。

### 9.4 短时保持与新观测

链路最近SINR在未超过 `max_link_age_ms` 时可以短时保持为模型输入，但只有：

```text
age < sampling_interval_ms
```

才计作该时隙的新观测。这样保持值不会重复冒充多个独立测量点。

## 11. 标准化

对应代码：

```text
src/sinr_predictor/data/normalization.py
```

标准化形式：

```text
z = (x - mean) / scale
```

关键原则：

1. 均值和尺度只从训练集拟合；
2. 验证集和测试集不参与统计量计算；
3. 缺失占位值不参与均值和方差；
4. 相同真实观测不会因窗口重叠被重复统计；
5. 标准化参数随 `model.pt`一起保存；
6. 推理时必须使用模型包中的相同统计量。

标准化伪代码：

```text
for each valid training observation:
    update running count, mean and variance

for each feature dimension:
    scale = standard deviation
    if scale is almost zero:
        scale = 1

transform(value, available):
    if available:
        return (value - mean) / scale
    else:
        return 0
```

## 12. 变规模图张量化

对应代码：

```text
src/sinr_predictor/data/tensors.py::tensorize_windows
```

对于一个时隙图：

| 张量 | 形状 | 含义 |
| --- | --- | --- |
| `nodes` | `[N, 32]` | N个节点输入特征 |
| `edges` | `[E, 18]` | E条有向边输入特征 |
| `edge_index` | `[2, E]` | 每条边的发送端和接收端索引 |
| `query_sources` | `[Q]` | Q条查询的发送端节点索引 |
| `query_destinations` | `[Q]` | Q条查询的接收端节点索引 |
| `query_edges` | `[Q]` | 查询对应的边索引 |
| `query_valid` | `[Q]` | 该查询在当前时隙是否有效 |

每个历史时隙允许有不同的 `N` 和 `E`，因此模型不要求固定节点数。

张量化伪代码：

```text
for each of 10 graph snapshots:
    sort node IDs and edge keys for deterministic indexing
    node_tensor = normalized values + masks + age + is_new
    edge_tensor = normalized values + masks + age + is_new
    edge_index = map source/destination IDs to integer indices

    for each query:
        if query endpoints and edge exist:
            record source, destination and edge indices
            query_valid = true
        else:
            indices = -1
            query_valid = false
```

## 13. GraphLSTM网络结构

对应代码：

```text
src/sinr_predictor/models/graph_lstm.py
```

### 13.1 单时隙节点和边编码

```text
node_hidden = NodeMLP(node_input_32)       → [N, 64]
edge_hidden = EdgeMLP(edge_input_18)       → [E, 64]
```

MLP结构：

```text
Linear → SiLU → Linear
```

### 13.2 有向消息传递

对于边 `u → v`：

```text
message(u→v) = MessageMLP([node_u, node_v, edge_uv])
```

每个接收节点只聚合进入自己的有向边：

```text
aggregate_v = mean(message(u→v) for all incoming u)
```

节点更新：

```text
new_node_v = LayerNorm(
    node_v + UpdateMLP([node_v, aggregate_v])
)
```

正式配置重复两层消息传递。

对应类：

```text
DirectedMessageLayer
```

### 13.3 查询链路编码

对查询边 `source → destination`：

```text
query_input = [source_node_hidden,
               destination_node_hidden,
               directed_edge_hidden]

link_embedding = QueryMLP(query_input) → 64维
```

再追加一维有效标志：

```text
per_step_link_input = [link_embedding, valid_flag] → 65维
```

查询在某个历史时隙不可用时，该时隙输入为全零，并且 `valid_flag=0`。

### 13.4 时间建模

同一查询链路的10个时隙表示堆叠为：

```text
[Q, 10, 65]
```

送入单向LSTM：

```text
LSTM(input_size=65, hidden_size=64, layers=1)
```

取最后一层最终隐藏状态：

```text
final_hidden = hidden[-1] → [Q, 64]
```

输出层：

```text
prediction = Linear(64, 3) → [Q, 3]
```

输出是标准化空间中的未来3步SINR，`TorchBackend`再还原到原始dB单位。

### 13.5 模型前向伪代码

```text
function GraphLSTM.forward(10_graphs):
    temporal_sequence = []

    for graph in 10_graphs:
        node_h = node_encoder(graph.nodes)
        edge_h = edge_encoder(graph.edges)

        repeat graph_layers times:
            node_h = directed_message_layer(node_h, edge_h, edge_index)

        for each query:
            if query is valid:
                link_h = query_encoder(
                    node_h[source],
                    node_h[destination],
                    edge_h[query_edge]
                )
                append [link_h, 1]
            else:
                append zeros(65)

        temporal_sequence.append(all query embeddings)

    sequence = stack as [Q, 10, 65]
    final_hidden = unidirectional_lstm(sequence)
    return linear_head(final_hidden)  # [Q, 3]
```

## 14. 三种空间模式

`NetworkConfig.spatial_mode`支持：

| 模式 | 输入 |
| --- | --- |
| `graph` | 完整节点、边和邻居消息聚合，正式默认 |
| `endpoints` | 节点和边编码，但不聚合邻居 |
| `quality` | 只使用SINR、SINR掩码、年龄和新观测标志 |

这三个模式用于消融实验，比较图邻居信息、端点状态和纯SINR历史的贡献。

## 15. 训练损失与掩码

对应代码：

```text
src/sinr_predictor/models/graph_lstm.py::masked_mse
src/sinr_predictor/training/graph_train.py::_supervision
```

未来某一步SINR可能没有真实标签，因此使用 `target_mask`：

```text
loss = mean((prediction - target)^2 only where target_mask == true)
```

伪代码：

```text
valid_errors = []

for query in queries:
    for horizon in [1, 2, 3]:
        if target_mask[query, horizon]:
            valid_errors.append(
                (prediction[query, horizon] - target[query, horizon])²
            )

loss = mean(valid_errors)
```

缺失标签不进入损失，也不产生梯度。

```text
job = read formal_graph_training.toml

for epoch in 1..max_epochs:
    shuffle training samples with fixed seed

    for mini_batch in training samples:
        optimizer.zero_grad()
        prediction = model(tensorized history graphs)
        loss = masked_mse(prediction, future targets)
        loss.backward()
        clip gradient norm
        optimizer.step()

    validation_rmse = evaluate current model on validation set

    if validation_rmse improves enough:
        copy model weights as best_state
        stale_epochs = 0
    else:
        stale_epochs += 1

    if stale_epochs >= patience:
        break

restore best_state
evaluate validation and independent test set
save model.pt
save report.json
```

```text

```

### 16.2 梯度裁剪

```text

```

## 17. 评估指标和基线

对应代码：

```text
src/sinr_predictor/training/evaluate.py
src/sinr_predictor/models/backends.py
```

### 17.1 MAE

```text
MAE = mean(|prediction - target|)
```

### 17.2 RMSE

```text
RMSE = sqrt(mean((prediction - target)²))
```

### 17.3 Bias

```text
Bias = mean(prediction - target)
```

正值表示整体高估，负值表示整体低估。

### 17.4 命中率

当前容差为3 dB：

```text
HitRate = count(|prediction - target| <= 3 dB) / comparable_count
```

### 17.5 基线

报告同时比较：

- `graph_lstm`：当前神经网络；
- `persistence`：未来值等于最近一次有效SINR；
- `history_mean`：未来值等于历史有效SINR均值。

神经网络结果必须与简单基线一起解释。

### 19.1 在线推理伪代码

```text
predictor = load model.pt

function predict(current_request):
    reference_time = cluster_head_current_time()

    parse and validate request
    if observation_time is missing:
        observation_time = reference_time

    reject future observations
    reject time going backwards
    reject self-loop relation

    history.ingest(request, arrived_at=reference_time)

    windows = build query windows
    statuses = check eligibility for every query
```

## 20. 预测资格判断

对应代码：

```text
src/sinr_predictor/data/eligibility.py
```

状态判断顺序：

```text
端点不存在、离簇或必要字段缺失
    → UNAVAILABLE

节点或链路观测过期
    → STALE_OBSERVATION

有效SINR比例不足或连续缺失过长
    → INSUFFICIENT_HISTORY

全部满足
    → SUCCESS
```

当前10步窗口至少需要8步新SINR观测，且不能连续缺失超过2步。

## 21. 节点数量变化和多簇使用

### 21.1 变节点数量

模型参数不依赖固定的节点编号或节点总数。每张图分别创建：

```text
[N, 32]节点张量
[E, 18]边张量
```

因此训练时和推理时可以出现不同的 `N` 和 `E`。

### 21.2 多簇共享模型

正确部署方式：

```text
cluster-1 Predictor ─┐
cluster-2 Predictor ─┼─ 加载同一个 model.pt
cluster-3 Predictor ─┘
```

每个Predictor的`HistoryCache`独立。可以共享模型参数，但不能把不同簇的节点和链路历史写入同一个缓存。
