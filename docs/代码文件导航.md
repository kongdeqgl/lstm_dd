# 代码文件导航（个人阅读版）

这份文档帮助你找到“某个功能到底在哪个文件里”。当前整理只调整目录、导入和说明，网络计算、训练规则、数据格式与模型包格式保持一致。项目要求 Python 3.12。

## 1. 先打开哪个文件夹

在 VS Code 中打开 `lstm_new`。根目录的 `README.md` 是操作入口，本文件是代码导航。

```text
lstm_new/
├─ README.md                   项目入口和运行命令
├─ config/                     手动修改的 TOML 参数
├─ docs/                       中文说明文档
├─ examples/                   人工构造的接口请求和响应示例
├─ scripts/
│  ├─ setup_env.py             Python 3.12 环境配置
│  └─ data_generation/         仿真场景生成、算料检查、转换命令
├─ src/sinr_predictor/         算法源码，下文重点
├─ tests/                      自动化测试
├─ outputs/                    训练数据、模型、报告、预测结果
├─ pyproject.toml              项目安装、依赖范围、命令入口
└─ requirements-lock.txt       便携依赖版本
```

`.venv` 是本机 Python 环境，`__pycache__` 是 Python 自动生成的缓存，都不需要作为算法源码阅读。

## 2. 源码按功能分类

```text
src/sinr_predictor/
├─ config.py                   公共运行配置
├─ schemas.py                  请求、响应、记录和状态码
├─ demo.py                     小型接口演示请求
├─ __init__.py                 对外提供 Predictor 等接口
├─ __main__.py                 python -m sinr_predictor 的入口
│
├─ data_generation/            ① 生成和转换实验数据
│  ├─ material_graph.py        仿真算料 → 图数据 JSON 分片
│  └─ synthetic.py             小型人工合成数据
│
├─ data/                       ② 公共数据处理
│  ├─ history.py               历史记录、到达时间、节点连续会话
│  ├─ preprocess.py            坐标转换、历史图、物理特征
│  ├─ eligibility.py           是否允许输出预测值
│  ├─ dataset.py               离线读取、划分、回放和标签构造
│  ├─ normalization.py         标准化统计量及变换
│  └─ tensors.py               图特征 → PyTorch 张量
│
├─ models/                     ③ 模型计算与模型包
│  ├─ graph_lstm.py            有向图编码器 + 链路级 LSTM
│  ├─ backends.py              统一预测协议和两种基线
│  └─ neural_backend.py        model.pt 保存、加载、数值预测
│
├─ training/                   ④ 训练与评估
│  ├─ graph_train.py           训练命令、训练循环、早停、导出
│  └─ evaluate.py              RMSE、MAE、命中率、可用率
│
└─ inference/                  ⑤ 在线推理
   ├─ predictor.py             接收新数据、维护历史、调用模型
   └─ cli.py                   从 JSON 文件发起一次推理
```

每个功能文件夹的 `__init__.py` 是 Python 包文件，主要用于导入管理。

顶层旧转发模块已删除，现在目录树对应实际代码。修改功能时直接进入对应子目录；公共配置、数据结构和包入口留在顶层。

## 3. 每个关键文件看什么

| 文件（相对 src/sinr_predictor） | 重点对象或函数 | 什么时候看 |
| --- | --- | --- |
| `config.py` | `ModelConfig` | 理解历史长度、过期阈值、缓存时间；日常调参优先改 TOML |
| `schemas.py` | `NodeRecord`、`RelationRecord`、`PredictionRequest`、`PredictionResponse` | 确认输入字段、单位、校验和输出格式 |
| `data/history.py` | `HistoryCache.ingest`、`latest_node`、`latest_relation`、`active_since`、`prune` | 理解去重、因果查询、节点退出重入和缓存清理 |
| `data/preprocess.py` | `build_snapshots`、`build_query_window` | 理解10个历史时隙怎样变成图、节点特征和边特征 |
| `data/eligibility.py` | `check_eligibility` | 查询为什么成功、历史不足、过期或不可用 |
| `data/dataset.py` | `load_episodes`、`split_episodes`、`build_samples` | 训练数据怎样读取、隔离划分、构造未来标签 |
| `data/normalization.py` | `Normalization.fit`、`FeatureStatistics.transform` | 训练集统计量怎样拟合、推理时怎样复用 |
| `data/tensors.py` | `tensorize_windows`、`TensorGraph` | 理解特征变成什么形状的张量 |
| `models/graph_lstm.py` | `DirectedMessageLayer`、`GraphLSTM.forward`、`masked_mse` | 修改图聚合、LSTM、预测头或损失 |
| `models/backends.py` | `PredictionBackend`、`PersistenceBackend`、`HistoryMeanBackend` | 理解模型接口和基线对照 |
| `models/neural_backend.py` | `TorchBackend.predict`、`load`、`save_bundle` | 模型加载失败、标准化恢复和模型版本问题 |
| `training/graph_train.py` | `GraphTrainingJob.from_toml`、`train_model`、`main` | 改训练流程、优化器、早停和命令参数 |
| `training/evaluate.py` | `evaluate_samples` | 增加分类评估、查看误差计算方式 |
| `inference/predictor.py` | `Predictor.from_model_bundle`、`predict` | 理解完整一次推理、在线缓存和结果封装 |
| `inference/cli.py` | `main` | 修改文件推理命令、输入输出路径和回放参数 |
| `data_generation/material_graph.py` | `convert_exports`、`convert_run` | 检查仿真器算料怎样转成训练文件 |
| `data_generation/synthetic.py` | `make_synthetic_dataset` | 生成快速验证所需的小型数据 |
| `demo.py` | `make_demo_request` | 理解 examples 的小型接口示例 |

`data` 表示公共数据处理，并不意味着每个文件都同时用于训练和推理：`dataset.py` 主要服务离线训练；`history.py`、`preprocess.py` 和 `eligibility.py` 由两条流程共同使用；`tensors.py` 需要 PyTorch。

## 4. 两条流程怎样连接

训练流程：

```text
config/formal_graph_training.toml
  → training/graph_train.py 读取训练任务
  → data/dataset.py 读取 JSON、按独立任务划分、回放历史
  → data/history.py + preprocess.py + eligibility.py 构造样本
  → data/normalization.py 只用训练集拟合统计量
  → data/tensors.py 构造输入张量
  → models/graph_lstm.py 前向计算、计算损失
  → training/graph_train.py 反向更新、验证早停
  → training/evaluate.py 独立测试并对比基线
  → models/neural_backend.py 保存 model.pt
```

在线推理流程：

```text
甲方当前时隙数据（整理成统一请求格式）
  → inference/predictor.py 接收请求
  → schemas.py 校验字段
  → data/history.py 追加当前记录、维护历史
  → data/preprocess.py 构造历史图和查询窗口
  → data/eligibility.py 筛选满足条件的链路
  → models/neural_backend.py 应用模型包中的标准化参数
  → data/tensors.py 构造输入张量
  → models/graph_lstm.py 预测未来3个时隙
  → inference/predictor.py 封装状态码和预测值
```

在线需要持续复用同一个簇的 `Predictor` 实例。历史只保存在内存中，重启后需要重新积累。不同簇可以使用同一份模型权重，但应维护各自的历史。

## 5. 建议你的阅读顺序

1. 先看 `schemas.py`，知道输入输出是什么。
2. 看 `inference/predictor.py` 的 `predict`，掌握推理流程。
3. 看 `data/history.py`，理解历史是怎样累积的。
4. 看 `data/preprocess.py`、`data/eligibility.py`，理解图和有效性判断。
5. 看 `data/tensors.py`、`models/graph_lstm.py`，理解模型维度和计算。
6. 最后看 `data/dataset.py`、`training/graph_train.py`、`training/evaluate.py`，理解训练和评估。

暂时不用从环境安装脚本或仿真生成代码开始阅读。

## 6. 改哪个功能就找哪个文件

| 想做的事情 | 优先修改位置 |
| --- | --- |
| 调整训练轮数、学习率、历史长度 | `config/formal_graph_training.toml` |
| 修改网络结构或尝试变化量预测 | `models/graph_lstm.py`，以及相关标签、还原和模型包代码 |
| 增加评估指标 | `training/evaluate.py` |
| 增加中途保存、断点恢复 | `training/graph_train.py` |
| 加快历史查询 | `data/history.py` |
| 改节点或链路物理特征 | `data/preprocess.py`，同时检查张量、标准化和模型包版本 |
| 改张量批处理 | `data/tensors.py`，配合训练和模型调用 |
| 对接甲方 CSV、网络消息或其他原始格式 | 另写面向甲方格式的适配代码，输出 schemas/dataset 约定的格式 |

当前 `data_generation/material_graph.py` 是仿真平台适配器，不是任意甲方格式的通用转换器。

## 8. 运行方式

训练入口现为 `sinr_predictor.training.graph_train`，旧的顶层训练模块已删除。推理命令及 `from sinr_predictor import Predictor` 保持不变。在 `lstm_new` 目录执行：

```powershell
# 查看训练参数，不会开始训练。
.\.venv\Scripts\python.exe -m sinr_predictor.training.graph_train --help

# 使用正式训练配置；实际运行时建议指定新的输出目录。
.\.venv\Scripts\python.exe -m sinr_predictor.training.graph_train `
  --training-config config\formal_graph_training.toml `
  --output outputs\organized_training_model

# 加载现有正式模型，使用固定时间回放接口示例。
.\.venv\Scripts\python.exe -m sinr_predictor `
  --request examples\request.json `
  --model outputs\complete_graph_training_v1\formal_model\model.pt `
  --replay-time-ms 1700000010000 `
  --output outputs\organized_prediction.json

# 自动化测试。
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

甲方如果不使用虚拟环境，并已安装本项目，可将解释器替换为 `py -3.12`。

这次目录整理不会触碰 `outputs` 中已有的48个图数据分片、正式模型与报告。此前生成的 ZIP 是独立快照，不会随本地文件自动更新。
